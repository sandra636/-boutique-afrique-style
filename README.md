# Boutique Afrique Style

## Description
Site vitrine d'une boutique en ligne proposant des produits artisanaux africains : masques, tissus, sculptures, bijoux et bien d'autres.

## Équipe
- **Membre A** : Mainteneur + Page d'accueil
- **Membre B** : Page catalogue
- **Membre C** : Page contact
- **Membre D** : Design global et README

## Fonctionnalités
- Page d'accueil avec présentation
- Catalogue avec grille de 6 produits et compteur panier
- Formulaire de contact avec validation
- Design responsive
- Menu de navigation

## Installation
```bash
git clone https://github.com/[username]/boutique-afrique-style.git
cd boutique-afrique-style
```

## Utilisation
Ouvrir `index.html` dans un navigateur ou lancer un serveur local.
